<decisions>
- D9-7 Generation: `Hub.next_gen: u64`; `Active.gen` set in `start`; `Hub::active_gen() -> Option<u64>`; `Hub::interrupt_if(gen, reason: Interrupt) -> bool` = if active gen == gen: take active, `finish_active`, store `(false, msg::interrupted(reason, t, path, finish_text))` in `orphaned`, return true; else false. Reuses finish_active so per-tab and follow modes both finalize every file.
- D9-8 Guard (`hub/guard.rs`): `spawn(hub: &'static Mutex<Hub> | Arc<Mutex<Hub>> (generic over a small `HubRef` trait or two constructors), gen, tick)`. Each tick: lock, read gen + `Tracker::browser_lost()` + `Encoder::is_dead()` (cheap, no await under lock except the finish), trigger -> `interrupt_if`; gen mismatch or not active -> exit. Spawned by hub.rs global path after `try_handle` record-start Ok (tests spawn it on their own Arc<Mutex<Hub>>). Tick 2 s const `GUARD_TICK`; Knobs gains `guard_tick: Option<Duration>`.
- D9-9 Interrupt reasons and text (msg.rs, scrubbed, no DEAD_TAB substrings): `browser connection lost`, `encoder exited (<exit text>)`; text `previous recording interrupted: <reason> at <T> s; partial file kept: <path>` plus the finish verdict words (`finalized` when ffmpeg exited 0 after EOF, else `unfinalized`). When a 09-01 shutdown hook (`finish_best_effort`) wins the race, its existing prefix stands; the guard then sees gen mismatch and exits.
- D9-10 Chrome kill with no further calls: the follower marks lost after 3 failed probes (~0.6 s at 200 ms poll), the guard finalizes within one guard tick: file playable to the cut without any agent call. Relaunch drift/crash/Closed: the 09-01 hooks finalize first (finish_orphan path); guard is a backstop.
- D9-11 Orphans: `ProcInfo { pid, ppid, argv: Vec<String> }`. Linux lister: /proc/<pid>/cmdline (NUL-split, exact) + stat ppid; macOS lister: `ps -axo pid=,ppid=,command=` (space-joined: the output path is matched as the TAIL of the command string after ` -f webm ` / ` -f mp4 ` and checked with `Path::new(tail).parent() == dir`, never by split). `classify(p, dir, alive: impl Fn(u32)->bool) -> Verdict::{Orphan, Keep(&'static str)}`. `sweep_in(dir, lister, killer) -> Vec<(u32, Verdict)>`; `sweep()` = no-op on Windows / no recordings dir, else detached thread. Killer: SIGTERM, poll 100 ms up to 2 s, re-read command line of that pid, SIGKILL only on exact match. One `tracing::info!` line per killed pid; nothing on stdout.
- D9-12 Fake processes: `Command::new("/bin/sh").arg0("ffmpeg").args(["-c", "trap 'exit 0' TERM; while :; do sleep 0.2; done", "ffmpeg", <bladebro argv..., <scratch dir>/<valid name>.webm>])` so `ps` shows argv[0] `ffmpeg` and the bladebro sequence; orphaned variant via an intermediate `sh -c '<that> & echo $!'` that exits (ppid becomes 1; read pid from stdout). Keep variants: live parent (direct child of the test), path in another dir, missing `-i pipe:0`, argv[0] `ffmpegx`, name pattern mismatch. Cleanup: the test SIGKILLs every pid it spawned in a drop guard. If the argv0 override does not show in `ps` on this macOS, adapt the FAKE (e.g. a copy or symlink of /bin/sh literally named `ffmpeg` in a scratch bin dir) so the real rule matches; never loosen `classify` for tests. Record what worked in the SUMMARY.
</decisions>
