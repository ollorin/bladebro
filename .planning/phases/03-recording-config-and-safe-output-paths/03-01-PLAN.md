<decisions>
Decisions taken in planning (document each in a `//` or `///` comment where it is implemented):
- D3-1 Explicit invalid values are REJECTED, never clamped. A clamp silently changes what the agent asked for; an error names the source (`BLADE_RECORD_FPS`, `record.json`, `per-call`) and the valid range. Odd sizes are rejected too (not rounded), with a hint of the nearest even size.
- D3-2 record.json uses `deny_unknown_fields`: a typo (`"fsp": 12`) must not be silently ignored in a user-edited file.
- D3-3 Per-call overrides carry name, format, fps, size only. NO per-call dir: the caller is an LLM that may be prompt-injected; the output directory is an operator decision (env/config). The name is sanitized in 03-02.
- D3-4 BLADE_RECORD must be an absolute path (the daemon's cwd differs from the CLI's, so a relative path is ambiguous). `0|off|false|no` (case-insensitive) = off, `1|on|true|yes` = on with the default dir, unset/empty = not set (falls through to config).
- D3-5 Quality and queue length are not env-tunable: quality only via record.json (range 1..=100, default 70), queue length is a constant 16. Fewer env vars = less surface.
- D3-6 Size bounds: each side even, width 160..=3840, height 120..=2160. Format accepts `webm` | `mp4` (case-insensitive, trimmed).
</decisions>
