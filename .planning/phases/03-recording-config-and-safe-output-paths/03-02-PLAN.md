<decisions>
Decisions taken in planning (document each in a comment where implemented):
- D3-7 Sanitize, do not reject: every char outside [A-Za-z0-9._-] becomes '_', runs of '_' collapse to one, leading chars in "-._" and trailing chars in "-._" are trimmed, the stem is capped at 80 bytes (ASCII by then) and re-trimmed. Empty result -> "recording". The agent always gets a file; the result path (later phases) shows the real name.
- D3-8 Windows reserved device names (CON, PRN, AUX, NUL, COM1-9, LPT1-9; case-insensitive; compared on the part before the first '.') get the prefix "rec_" on every OS, so a name means the same file on every platform.
- D3-9 A caller name never overwrites anything: the name always carries a UTC timestamp and a 6-hex id, and creation uses create_new with up to 8 attempts.
- D3-10 Recordings dir: refuse if it is a symlink or not a directory; refuse if owned by another user (Unix); otherwise create (mkdir for the last component) or reuse and set 0700, including tightening a pre-existing looser dir (same as BLADE_PROFILE_DIR in session_profile.rs). README (03-03) tells users to point BLADE_RECORD at a dedicated directory because of this.
- D3-11 Windows: no mode bits; the file inherits the directory ACL (decision written in 03-03 WINDOWS-ACL-DECISION.md). The non-unix branch keeps the portable checks (symlink, is_dir, create_new, parent == canonical dir).
</decisions>
