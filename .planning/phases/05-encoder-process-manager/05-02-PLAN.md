<decisions>
- D5-9 Resolve: `ResolvedFfmpeg { pub path: PathBuf, pub version: FfmpegVersion, pub encoders: EncoderSet }` is format-agnostic; the encoder check happens in `Encoder::start` for the requested format, so tests build a ResolvedFfmpeg for a fake binary directly (no probe). Mapping in `resolve_from(d, os)`: NotFound -> FfmpegNotFound{install_hint(os)}; OverrideUnusable -> OverrideUnusable; Found + probe None -> FfmpegUnusable "was not probed"; Found + Some(Err(e)) -> FfmpegUnusable e; Found + Ok but `!encoders.listed` -> FfmpegUnusable "could not read its encoder list"; else Ok. `resolve_ffmpeg()` = `spawn_blocking(discover_cached)` then resolve_from(.., TargetOs::current()); a JoinError -> FfmpegUnusable { path: "(discovery)", reason: "discovery task failed: {e}" }.
- D5-10 Start order (each before any process exists): encoder present for spec.format (EncoderMissing, alt = the other format if its encoder is present) -> build_args (BadOutputPath) -> `tokio::runtime::Handle::try_current()` (Spawn "no async runtime: call from inside the daemon/MCP tokio runtime"; tokio's spawn would otherwise panic) -> spawn (Spawn with the io error text). Env is inherited; no current_dir change.
- D5-11 Writer task owns ChildStdin and the Pacer. Loop: `tokio::select! { biased; msg = rx.recv() => ..., _ = tick.tick(), if pending.is_some() && rx.is_empty() => ... }` with `interval(HOLD_FLUSH_INTERVAL = 1 s)`, MissedTickBehavior::Delay. On a frame: n = pacer.on_frame(ts); write the previous pending frame n times; new frame becomes pending (with its arrival Instant). On a tick: est = pending.ts + pending.arrived.elapsed() ms; write pending advance_to(est) times (the hold is written while idle, so finish has at most ~1 s of backlog). On channel close: end = pending.ts + (end_at - pending.arrived) where `end_at` is the Instant finish() stored before dropping the sender (missing -> +0); write on_end(end) times; flush; drop stdin (EOF). First write error: store its text (first error only), stop writing, drop stdin, end the task. Counters (frames_written, gaps_clamped) are `Arc<AtomicU64>` so they survive an abort; write_error and end_at are `std::sync::OnceLock` in the same shared struct (no mutex). Rust ignores SIGPIPE, so a dead reader yields EPIPE (an error value), never a signal.
- D5-12 finish(self), one deadline = now + finish_timeout: set end_at; drop the Sender; `timeout_at(deadline, &mut writer)`; on expiry `writer.abort()` and await it (abort drops ChildStdin -> EOF is delivered even when ffmpeg stopped reading); `timeout_at(deadline, child.wait())`: Ok(status) -> Code(c) or Signal(status.to_string()); Err(io) -> WaitFailed; expiry -> `timeout(KILL_REAP_TIMEOUT = 5 s, child.kill())`: Ok(Ok) -> Killed{reaped:true}, else Killed{reaped:false}. Then the stderr task with `timeout(STDERR_DRAIN_GRACE = 1 s)` (ffmpeg is spawned directly, so its exit closes the pipe; abort on expiry). bytes = `std::fs::metadata(out)` if `is_file()`. Outcome = classify(...). finalize_ms from the start of finish. kill_on_drop(true) stays as the backstop for an Encoder dropped without finish (Phase 9 owns that path); it is never the finalizer.
- D5-13 send_frame(&self, jpeg: Vec<u8>, timestamp_ms: u64) -> bool: `try_send(Frame { jpeg, ts_ms, arrived: Instant::now() })`; Ok -> frames_queued += 1, true; Full or Closed -> frames_dropped += 1, false. &self + atomics so Phase 6 can share the encoder behind an Arc. The channel capacity is `EncoderConfig.queue_len.max(1)` (QUEUE_LEN 16 by default).
- D5-14 Windows (reasoned from 05-RESEARCH.md and the tokio source; not compiled or run here): `#[cfg(windows)] { const CREATE_NO_WINDOW: u32 = 0x0800_0000; cmd.creation_flags(CREATE_NO_WINDOW); }`. No SIGINT path exists; EOF on stdin is the only graceful stop and it is the same code path as unix. The parent holds exactly one stdin handle (moved into the writer; no try_clone), so dropping it delivers EOF. Kill = TerminateProcess; always followed by wait.
</decisions>
