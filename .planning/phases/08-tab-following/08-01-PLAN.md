<decisions>
- D8-1 Agent-tab rule (pure `agent_tab(list: &[TabView], bound: &[String], rule: Rule) -> Option<String>`), `Rule::Attached` (research section 1 steps 1-4) and `Rule::ListOrder` (step 5: first non-devtools page). `const RULE` picks one; Task 1 discovery decides which (default Attached). `bound` = every tab id the follower holds a socket to (current + still-retiring). Confirm: switch only when the same candidate is seen on two samples ~50 ms apart (`CONFIRM`). `POLL = 200 ms` const. Rapid A->B->C inside one poll: the latest confirmed candidate wins, skipped tabs get no segment (documented).
- D8-2 Rebind order: start the new Source first (`Source::start_ws(view.ws_url)`), then bump `current_gen` (new `Arc<SegmentSink>`), then retire the old Source with `tokio::spawn(old.stop())` kept in `pending`. Never await an old stop on the tick path. A failed start keeps the old binding, retries on the next 2 ticks, then records `rebind_failed` (not clean) and keeps retrying each tick.
- D8-3 `SegmentSink { inner: Arc<dyn FrameSink>, gen, shared: Arc<FollowShared> }`: `send_frame` returns true and discards when gen != current or ts < last accepted ts (counted in `stale`, reported in SUMMARY/debug, not as dropped: the agent was no longer on that tab); `mark_end` is a no-op. The follower calls `inner.mark_end()` itself once at final stop. `inner` is the shared Encoder as `Arc<dyn FrameSink>` (same allocation, so `take_encoder` works once every sink is dropped) or a counting sink in unit tests.
- D8-4 Close / gone / browser lost / no tab: per research section 4. Probe Ok + bound id absent, or current Source `is_finished()` -> rebind to `agent_tab` with note `tab A gone at T s; following tab B` (clean if the rebind succeeds; covers close-tab and a target-id change, which are indistinguishable from outside). Probe Err on 3 consecutive ticks -> stop polling, keep encoder, mark lost (not clean). No page -> `no tab left at T s` (not clean); the recording stays Active until record-stop, which keeps the file and says so. Cross-origin with WS + id surviving but frames stopping: only if Task 1 discovery shows it, Task 2 re-sends `Page.startScreencast` (an existing RecMethod) on `Page.frameNavigated` in source/handler.rs (fork-owned) and the SUMMARY says so; otherwise no change.
- D8-5 Merge (pure, table-tested): sum stats (frames_received, forwarded, lost, queue_dropped, capped, bad_frames); outcome: total 0 frames -> NoFrames; any unrebound ConnectionLost / browser lost / no-tab / rebind failure -> not clean with that text; a segment with 0 frames lasting >= no_frames_after -> not clean `tab X: no frames for N s (hidden or background tab)`; shorter -> segment label `X (no frames)`, clean; a rebound ConnectionLost is not a failure; quiet_tail from the last segment only. `compose` (report.rs) is reused unchanged with the merged report, segments and notes joined by "; ".
- D8-6 Hub wiring: `Active.src: FrameSource` -> `Active.rec: follow::Tracker`. `Tracker::spawn(probe, first: Source-start inputs, enc, cfg, knobs)` binds the record-start tab exactly as Phase 7 (Endpoint::Port retry path; Attach::Ws in tests). `msg::active` uses `tracker.health()` (current source). `Hub::stop` reads `env.current_tab()` and passes it as `hint` to `tracker.stop(hint)`: when hint != bound and present in the list, rebind first (catch-up), then `mark_end`, stop current (one grace), join pending (each already bounded inside Source::stop), drop every sink, return `FollowResult`; then `take_encoder` + `finish` + `compose` as today. `finish_orphan` -> `stop(None)`. Dropping a Tracker aborts the task (Sources abort on drop; encoder kill_on_drop backstop). `msg::tab_moved` and test `k_` are deleted and replaced.
- D8-7 `HubEnv` gains `fn probe(&self) -> TabProbe` with a DEFAULT body: `Attach::Port(base)` -> `TabProbe::Http { base }`; `Attach::Ws(_)` -> `TabProbe::Fixed` (list = the bound tab only: Phase 7 behavior, so every existing machine test stays valid). Tests use `TabProbe::Scripted(Arc<Mutex<Vec<TabView>>>)`. `Knobs` gains `poll`, `confirm`, `no_frames_after` (test-shortened; None keeps the consts). `live_env.rs` needs no change (default body).
- D8-8 Source API: only `pub fn is_finished(&self) -> bool` (3 lines, capture.rs). FakeCdp gains `FakeOpts.ts_base: f64` (default 1.7e9, used by frame_ts) so two fakes can model Chrome's shared clock. No other source change unless D8-4's contingency triggers.
- D8-8b Start text unchanged; `[<offset> s tab <id>]` keeps the full target id (matches `state tabs`). New msg fns: `tab_gone`, `no_tab`, `browser_lost`, `rebind_failed`, `zero_frames`; none contains a DEAD_TAB substring (assert in tests).
