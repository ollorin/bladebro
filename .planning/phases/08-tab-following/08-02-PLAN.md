<decisions>
- D8-9 `pub enum Tabs { #[default] Follow, PerTab }`, `Tabs::parse` (trim, ASCII case-insensitive, `follow` | `per-tab`; error `must be follow or per-tab (got "<v>")`), `pub const ENV_RECORD_TABS: &str = "BLADE_RECORD_TABS"` beside ENV_RECORD_SIZE. `FileConfig.tabs: Option<String>`, `RecordOverrides.tabs: Option<String>`, `RecordConfig.tabs: Tabs`, `Parsed.tabs`, precedence like format. live_env.rs still passes only `name` (no per-call tabs from the state tool). Fix every `RecordConfig { .. }` literal (grep: layered.rs, encoder/process.rs, encoder/args.rs, hub/machine_tests.rs, tests/record_live.rs).
- D8-10 `names::tab_stem(stem: &str, n: u32) -> String`: sanitize, cut to `MAX_STEM - 6` chars (char boundary), append `-tab<n>`; n = first-visit order starting at 1; the record-start tab is tab1. File via `create_recording_file` with a cloned cfg whose `name = Some(tab_stem(..))`.
- D8-11 Policy (files.rs): `enum Policy { One(Arc<Encoder>), PerTab(Files) }`. `Files { cfg: RecordConfig, ecfg: EncoderConfig, map: tab id -> TabFile { enc: Option<Arc<Encoder>>, path, n, shared: Arc<FollowShared>, segments }, open: usize, finalizing: Vec<JoinHandle<(path, EncoderReport)>>, notes }`. Agent enters tab X: has an open TabFile -> new Source into its SegmentSink (new gen of that file's FollowShared); else if open < MAX_TAB_FILES -> create file + Encoder::start (failure -> note, not clean; follower keeps retrying only on the next entry to X, not every tick) + Source; else cap note (once per tab), no Source (the previous tab's source still retires). Each file has its own FollowShared (its own t0, gens, first_ts), so offsets are per file.
- D8-12 Dormant file timeline: an encoder whose tab the agent left holds its last frame (pacer) until revisit or stop; the file spans first visit -> stop (or close). Documented; `MAX_GAP_MS` clamp applies (gaps_clamped). Finishing on leave was rejected (breaks one file per tab on return).
- D8-13 Tab close in per-tab mode (id absent from the list or its Source finished while its tab is gone): `mark_end` on that encoder, retire its source, drop its sink, spawn finalize (`take_encoder` 20x50 ms then `finish`, bounded by finish_timeout), `open -= 1`. A tab that disappears while dormant (no source) is finalized the same way. Not a failure; the file's line carries `closed at T s` in its segments note.
- D8-14 Stop (per-tab): `mark_end` every open encoder, stop the current source (one grace), join pending sources, then finish all open encoders concurrently (`futures_util::future::join_all`, already a dependency) and join `finalizing`; each finish is bounded by finish_timeout; an outer timeout (finish_timeout + 2*grace + 5 s) aborts and reports the unfinished file as `not finalized`. `finish_orphan` uses the same path.
- D8-15 Result (follow_report.rs, pure): `compose_per_tab(files: &[FileOutcome{src: SourceReport (merged per file), enc: EncoderReport, segments}], fps, notes) -> (bool, String)`; files ordered by n; `ok` = every file src.ok && enc.ok and no not-clean note (rebind/create failure, browser lost, no tab); header `recording saved (per-tab, N files): ` or `recording not clean (per-tab, N files): <first failing verdict, prefixed tab <id>:>; `; files joined by `; `; notes appended as `. Note: a; b`. Cap note is a note with a clean result when nothing else failed (a documented operator limit, the tab is named with the time it went unrecorded; flag this choice to the coordinator in the SUMMARY). Start text in per-tab mode: `recording started (per-tab files): <path of tab1> (tab <id>); ...` (msg.rs). `msg::active` names the first file and `N files`.
</decisions>
