All files ESM, Node built-ins only. Short "why" comments.

**lib/cdp.mjs** exports:
- `parseDevToolsActivePort(text)` -> `{port:number, browserPath:string}`; throws on malformed (pure).
- `async getJson(port, path)` -> `fetch('http://127.0.0.1:'+port+path)` JSON.
- `async connect(wsUrl)` -> object `{ send(method, params={}, sessionId), on(method, fn(params, sessionId)), onAny(fn), close(), closed: Promise }`. Uses global `WebSocket`. Ids increment; `send` returns a Promise resolved with `result` or rejected with the CDP `error`; message routing: `msg.id` -> pending map, else event -> handlers for `msg.method` with `(msg.params, msg.sessionId)`. `sendNoWait(method, params, sessionId)` returns `{id, sentAt, done: Promise}` without awaiting (used for acks). Reject all pending on close.
- `percentile(sortedArr, p)` (pure, p in 0..100, nearest-rank; empty -> null).

**lib/encoder.mjs** exports:
- `even(n)` -> `n - (n % 2)`.
- `buildFfmpegArgs({codec, ts, out, width, height, sizeMode, fps, concatList})` (pure) returns argv array (no shell). Layout:
  - common head: `-hide_banner -nostats -loglevel info -benchmark -y`
  - input: ts `wallclock`: `-f image2pipe -c:v mjpeg -use_wallclock_as_timestamps 1 -i pipe:0`; ts `cfr`: `-f image2pipe -framerate <fps> -c:v mjpeg -i pipe:0`; ts `concat`: `-f concat -safe 0 -i <concatList>`.
  - filter `-vf`: sizeMode `fixed`: `scale=<even(width)>:<even(height)>:force_original_aspect_ratio=decrease:force_divisible_by=2,pad=<even(width)>:<even(height)>:(ow-iw)/2:(oh-ih)/2,format=yuv420p`; sizeMode `even`: `scale=trunc(iw/2)*2:trunc(ih/2)*2,format=yuv420p`.
  - timing out: wallclock and concat: `-fps_mode vfr`; cfr: `-r <fps>`.
  - codec `vp9`: `-c:v libvpx-vp9 -deadline realtime -cpu-used 8 -row-mt 1 -crf 40 -b:v 0`; `vp8`: `-c:v libvpx -deadline realtime -cpu-used 8 -crf 10 -b:v 2M`; `x264`: `-c:v libx264 -preset veryfast -crf 28 -movflags +faststart`.
  - `-an <out>` last. Throw on unknown codec/ts/sizeMode, and on extension mismatch (vp9/vp8 need `.webm`, x264 needs `.mp4`).
- `class FrameQueue(cap)`: `push(item)` returns false and increments `dropped` when full (drop the INCOMING/newest frame, per ROADMAP Phase 6); `shift()` async (resolves when an item exists or `close()` was called -> `null`); `length`, `maxSeen`, `dropped`, `close()`.
- `buildConcatList(entries, stopWallMs)` (pure): entries `[{file, tMs}]` (tMs = frame time in ms, monotonic); returns `ffconcat version 1.0\n` + `file '<f>'\nduration <sec with 6 decimals>\n` per entry where duration = next.tMs - this.tMs and for the last entry `stopWallMs - last.tMs` (min 0.001), then the last `file` line repeated once more (concat demuxer ignores the last duration otherwise). Empty entries -> throws.
- `parseBench(stderrText)` (pure): parse `bench: utime=1.234s stime=0.120s rtime=10.5s` -> `{utime_s, stime_s, rtime_s}` or null.
- `jpegSize(buf)` (pure): scan JPEG markers for SOF0/SOF1/SOF2 (0xFFC0/C1/C2) and return `{w,h}` or null.
- `startEncoder(ffmpegPath, args)`: `spawn(ffmpegPath, args, {stdio:['pipe','ignore','pipe']})`; keep a bounded stderr tail (last 64 KiB); returns `{child, write(buf): Promise (resolves after 'drain' if write returned false), finalize(timeoutMs): Promise<{exit_code, signal, finalized, killed, finalize_ms, bench, stderr_tail}>}`. finalize = `stdin.end()`, wait for 'exit' up to timeoutMs, else `SIGKILL` and `finalized:false, killed:true`. `finalized` true only if exit_code === 0. `stderr_tail` in the result = last 2048 chars.

**sidecar.mjs** CLI (parse `process.argv` by hand). Flags and defaults:
`--port N` (required in this plan) | `--target ID` (default: first `type==="page"` in `/json/list`) | `--out FILE` (required) | `--duration S` (default: until SIGINT/SIGTERM) | `--codec vp9|vp8|x264` (vp9) | `--ts wallclock|concat|cfr` (wallclock) | `--fps N` (10; cfr tick rate) | `--quality N` (70) | `--max-width N` (1280) | `--max-height N` (720) | `--every-nth N` (1) | `--queue N` (16) | `--slow-writer-ms N` (0) | `--size-mode fixed|even` (fixed) | `--no-page-enable` | `--no-tail` | `--stats FILE` (default `<out>.stats.json`) | `--finalize-timeout MS` (10000) | `--keep-frames` | `--ffmpeg PATH` (default `$BLADE_FFMPEG` else `ffmpeg`). Usage errors exit 2 with a one-line message.

Start sequence (exact CDP):
1. `getJson(port,'/json/version')` -> `webSocketDebuggerUrl`, `Browser`; `connect()` to that browser URL.
2. `Target.attachToTarget {targetId, flatten:true}` -> `sessionId` S.
3. unless `--no-page-enable`: `Page.enable` on S.
4. `Page.startScreencast {format:'jpeg', quality, maxWidth, maxHeight, everyNthFrame}` on S.

Frame handler on `Page.screencastFrame` (only when the event's CDP sessionId === S):
- FIRST, before anything else: `t0=performance.now()`; `ack = cdp.sendNoWait('Page.screencastFrameAck', {sessionId: params.sessionId}, S)`; record `ack_send_us=(performance.now()-t0)*1000`; on `ack.done` resolve record `ack_rtt_ms`, `acks_ok++`; on reject `acks_err++`. `acks_sent++`.
- then `frames_received++`, decode `Buffer.from(params.data,'base64')`, record `jpegSize`, `capture_to_recv_ms = Date.now() - params.metadata.timestamp*1000` when timestamp present, gap since previous frame, 1-second bucket counter (`fps_buckets[floor(elapsed_s)]++`).
- wallclock: `queue.push({buf})`; cfr: store as `latest` only; concat: write `f%06d.jpg` into `<out>.frames/` and push `{file, tMs}` where tMs = `metadata.timestamp*1000` if present else `Date.now()` (record which in stats `concat_clock`).

Writer loop (async, independent of the handler): `while ((f = await queue.shift()) !== null) { if (slowMs) await sleep(slowMs); await enc.write(f.buf); frames_written++ }`. cfr: `setInterval(1000/fps)` pushes `latest` (count `dup_frames_written` when same object as last tick; skip ticks before the first frame).

Stop (on duration timer, SIGINT, SIGTERM, or WS close): run once:
1. `Page.stopScreencast` on S (2 s timeout, ignore errors), `Target.detachFromTarget {sessionId:S}`.
2. wallclock without `--no-tail`: push the last frame once more (so the video spans to stop time); cfr: clear interval.
3. `queue.close()`, await writer drain (max 5 s).
4. wallclock/cfr: `enc.finalize(finalizeTimeout)`. concat: write `<out>.frames/list.ffconcat` via `buildConcatList(entries, stopTimeInSameClock)`, then run ffmpeg once with `buildFfmpegArgs({ts:'concat', concatList})` and finalize with max(finalizeTimeout, 60000); delete the frames dir unless `--keep-frames`.
5. Write stats JSON (schema below), close WS, exit 0 if `finalized && frames_received>0`, 3 if no frames, 1 otherwise.

Stats JSON keys (all present, null when not applicable): `version:1, args, chrome, ffmpeg_path, started_at, wall_ms, frames_received, acks_sent, acks_ok, acks_err, frames_written, dup_frames_written, frames_dropped, queue_max, ack_send_us{p50,p95,max}, ack_rtt_ms{p50,p95,max}, capture_to_recv_ms{p50,p95,max}, effective_fps_recv, first_frame_ms, max_gap_ms, fps_buckets[], frame_sizes{"WxH":count}, concat_clock, segments[{t_ms,targetId,url,frames}], events[], encoder{exit_code,signal,finalized,killed,finalize_ms,bench,stderr_tail}, out, out_bytes`. `segments` has one entry in this plan (02-02 adds more); `events` stays `[]` here.
